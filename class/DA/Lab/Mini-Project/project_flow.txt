## 🧹 **Step 2: Data Cleaning & Preparation**

### ✅ **Actions & Justifications**

| Task                    | Action                                                                     | Justification                      |
| ----------------------- | -------------------------------------------------------------------------- | ---------------------------------- |
| Handle Missing Values   | Drop rows with missing `price` or `release_date`                           | These are essential features.      |
| Format Dates            | Convert `release_date` → datetime; extract `release_year`                  | Needed for time-based analysis.    |
| Clean Owners            | Convert `owners` range (e.g., "1000000-2000000") to midpoint integer value | Enables numeric modeling.          |
| Encode Categorical Data | One-Hot Encode `genres` and `platforms`                                    | Converts text to usable features.  |
| Outlier Treatment       | Use IQR method on `price` and `average_playtime`                           | Prevent skewed regression results. |
| Normalize Features      | StandardScaler for numeric variables (`price`, `ratings`, `playtime`)      | Improves model performance.        |
| Feature Engineering     | Add new column `total_ratings = positive + negative`                       | Represents total engagement.       |
| Sentiment Ratio         | Create `rating_ratio = positive_ratings / (positive + negative)`           | Reflects quality of user response. |

## 🧪 **Step 4: Statistical Analysis & Hypothesis Testing**

### **Hypothesis Example 1:**

* **H₀:** Free-to-play games have the same average number of owners as paid games.
* **H₁:** Free-to-play games have significantly more owners than paid games.

🔹 **Test:** Independent **t-test** (compare owner count means)

### **Hypothesis Example 2:**

* **H₀:** Game genre does not affect the average playtime.
* **H₁:** At least one genre differs significantly in average playtime.

🔹 **Test:** **ANOVA** (compare mean playtime across genres)

### **Outputs:**

* p-values, confidence intervals
* Interpret which variables show significant relationships
